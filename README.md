# Ivan Alcantara Oviedo — Personal Website 2026

A static, responsive personal website designed around clarity, proof of work, accessibility, and fast loading.

## Included
- Evidence-first homepage
- Three detailed case studies
- Full experience section
- Skills grouped by how they are applied
- Athletics + leadership section
- HTML resume + downloadable DOCX
- Open Graph social preview image
- ProfilePage / Person structured data
- Keyboard-visible focus states and skip navigation
- Reduced-motion support
- Responsive mobile navigation
- Custom 404 page
- robots.txt

## Before publishing
1. Choose your final domain, then add a canonical URL and `og:url` to each page.
2. Add the domain to `robots.txt` with a Sitemap URL and generate a domain-specific sitemap.xml.
3. If you have a public GitHub profile you want employers to see, add it beside LinkedIn and connect repositories to the two technical case studies.
4. Replace or supplement the diagram visuals with real, sanitized screenshots when you have material that can safely be shown publicly.
5. If desired, add a professional portrait to the About section. The current site does not use a fake placeholder image.
6. Run Lighthouse after deployment and test the site on a real phone.

## Hosting
This is a static site and can be deployed directly to GitHub Pages, Netlify, Vercel, Cloudflare Pages, or any standard web host.

For GitHub Pages, upload the contents of this folder to a repository and enable Pages for the main branch.
